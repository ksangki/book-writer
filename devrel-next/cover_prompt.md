# Cover Design Log — 코드 너머의 관계

## Version 1 (2026-09-25)

- **콘셉트:** 타이포그래피 중심 + 연결 모티프 (시리즈 「코드 너머의 ~」 레이아웃 계승)
- **도구:** ImageMagick 7 (타이포그래피 방식 — 한글 제목·부제·저자를 정확히 렌더하기 위해 선택)
- **사이즈:** 1600 × 2560

### 검토한 콘셉트 3안
1. **(채택) 타이포 + 원·점·사각 연결선** — 원(사람/빌더)과 사각(에이전트)처럼 형태가 다른 두 존재를 중앙 노드(DevRel)가 잇는다. 양 끝의 흐린 선·점은 조직 안팎으로 이어지는 관계망.
2. 다리 실루엣 미니멀 — 두 기슭을 잇는 한 줄 아치. 메타포가 직접적이지만 시리즈 문법(수평선+점)과 어긋남.
3. 노드 그래프 필드 — 여러 형태의 노드가 흩어진 네트워크. 썸네일에서 소음이 되어 기각.
