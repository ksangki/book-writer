## 1. 수사 대구 — 가장 위험한 항목 (이 책은 대비 쌍이 주제다)

**장당 상한 3회.** 아래 형태를 모두 1회로 센다. style-guardian은 문장 분리형·헤딩 포함 엄격 기준으로 직접 센다.

| 세는 형태 | 예 |
|---|---|
| "A가 아니라 B다" | "청중이 줄어든 게 아니라 바뀌었다" |
| "~아니고 ~다" | "마케팅도 아니고 영업도 아니다. 번역이다" |
| 문장 분리형 | "DevRel은 죽지 않았다. 옮겨갔을 뿐이다." |
| "A보다 B" 강조형 | "직함보다 기능을 봐야 한다" |
| 대칭 병렬형 | "빌더는 만들고, 에이전트는 읽는다" / "대상은 ~, 수단은 ~" |
| 헤딩·그림 캡션의 대구 | 소절 제목을 대구로 바꾸면 그것도 1회 |

- **위험 쌍:** ① Dev/비Dev(전문 개발자/빌더) ② 사람/에이전트(human/machine funnel) ③ 외부/내부(생태계/조직) + 직함/기능, 죽었다/살았다, 콘텐츠/채널.
- **공인 대구 "직함은 흩어지고 기능은 남는다"** — 통권 정확히 3회: PART 3 제목 · 7장 본문 1회(7-1 또는 7-2) · 10장 본문 1회(10-2). 이 3회는 장당 상한에서 제외. **그 외 장·헤딩·서문·에필로그에서 쓰면 Critical.** 변형("직함은 사라져도 기능은 남는다" 등)도 사용으로 센다.
- **세지 않는 것:** 출처 인용문 속 대구(단, 인용 직후 저자 문장이 같은 대구를 되풀이하면 센다). 근거 고지형 부정("이것은 발표자의 주장이다. 회사 자료로는 확인되지 않는다") — 상한 없음, **문형만 변주**.
- **대체 서술 전략(장별):** 1 다항 서술 / 2 시간축·누적 / 3 스펙트럼·전문성의 재배치(동사로) / 4 중첩·공존 / 5 조건부·데이터 병치·셋으로 늘리기 / 6 1:many↔1:1 스펙트럼·대조표 / 7 기능 분해표·동사 / 8 동사 유지·대상 이동 / 9 설계 다이얼(강도·측정·공유 장치) / 10 다섯 구도+반대+관찰 지표.
- 요령: 대비가 떠오르면 **셋째 항을 넣거나**, **조건절("~라면")로 바꾸거나**, **동사 하나로 옮겨간 방향만 서술**하자.

## 2. 저자 목소리 — BLOCKING (위반은 스타일이 아니라 Critical)

**허용되는 1인칭은 이것뿐:**
1. 저자는 DevRel을 했다. 2. 저자는 지금 AX를 한다.
3. 공개 이력 — 정확히 이 문구: "데브챗 커뮤니티 출신 7인 공저 『코드 너머, 회사보다 오래 남을 개발자』(한빛미디어, 2025)". 데브챗의 성격·규모·"모임에서 만난" 등 장면 금지.
4. **본문에 제시한 공개 사례·이론에 대한 판단** — 예: "Angie Jones의 이 문장을 DevRel을 해본 사람으로서 읽으면 직무 설명처럼 읽힌다."

**금지(발견 즉시 Critical):**
- 장면: "그날 행사장에서", 대화·동료 발언, 회사·팀·시스템·인물 실명, 내부 건수·금액·비율·인원·날짜.
- 경험 관찰형 일반화: "해보니 / 겪어보니 / 해보면 알게 된다", "현장에서 보면 / 현장에서는 / 실무에서는 대개", "내가 본 조직들은 / 내가 만난 사람들은 / 내 경험상", 출처 없는 "대개 사람들은 ~ / 많은 팀이 ~ / 보통 첫 반응은 ~", "DevRel 시절 나는 ~했다" 식 행위 서술.
- 가정 장면이 필요하면 **독자 주어 상황 가정**("당신이 ~라고 해보자")으로.
- 본문에 `[저자 입력]` 류 마커 금지 — 필요 지점은 `author_input_needed.md`에만.

**궤적 문장("DevRel을 했고 지금은 AX를 한다") 배치:** 서문 전문 1회 / PART 4 도입 질문만 / 7-5 한 문장 / 8장 재진술 없음(허용 4 두 문단 이내) / 10-6 회고 한두 문장 / **그 외 장은 쓰지 않는다.**

| 장 | 저자 목소리 허용량 |
|---|---|
| 1 | 허용 4 형식 1~2문장 |
| 2 | 공개 이력 문구 1문장 가능. 계기 서술 금지 |
| 3 | 허용 4 해석 1문장 이내 |
| 4 | 없음 |
| 5 | 허용 4 1문장 이내 |
| 6 | 허용 4 1~2문장 |
| 7 | 7-5 궤적 1문장 + 허용 4 1~2문장, 7-4 공개 이력 1회 가능 |
| 8 | 허용 4만, 두 문단 이내 |
| 9 | 허용 4 두세 문장 |
| 10 | 10-6 회고 한두 문장 + [이 책의 전망](체험 근거 금지) |

## 3. 오프닝·클로징 배정 (변주 배정표 — 바꾸지 말 것)

| 장 | 오프닝 | 클로징 | 스캐폴드 | `### 이 장의 핵심` | 반론 박스 |
|---|---|---|---|---|---|
| 1 | 인용·일화 (Salma) | 질문 남기기 | 사례 분석 | - | - |
| 2 | 정의 뒤집기 | 한 문장 여운 | 개념 도입 | O | - |
| 3 | 충격 수치·사실 (Scaffidi·Ko) | 적용 과제 | 사례 분석 | - | - |
| 4 | 상황 가정 (당신이 Supabase DevRel) | 반론으로 긴장 (xena) | 개념 도입 | O | O |
| 5 | 실패 장면 (Tailwind PR) | 짧은 매듭 + PART 전환 이음 | 문제-해결 | - | O |
| 6 | 상황 가정 (2026-09-25 채용 페이지) | 한 문장 여운 (공고 한 줄) | 비교 대조 | - | O |
| 7 | 수사적 질문 | 리더에게 질문 + 부록 A 연결 | 개념 도입 | O | - |
| 8 | 인용·일화 (Angie Jones) | 한계 고지로 긴장 | 사례 분석 | - | - |
| 9 | 앞 장 콜백 | 적용 과제 | 문제-해결 | O | - |
| 10 | 충격 수치·사실 (Amodei) | 회고형 닫는 매듭 | 종합 정리 | - | O |

- 메타 선언 오프닝("이 장에서는 ~를 다룬다") 금지.
- 중간 장에 `## 마무리` 헤딩 금지. "다음 장에서는 ~를 다룬다" 문형은 **책 전체 최대 2회**(누가 썼는지 로그에서 추적한다 — 쓰기 전에 style-guardian에게 확인하는 편이 낫다).
- `### 이 장의 핵심`은 2·4·7·9장에만, 헤딩 표기 정확히 이대로, 3~5불릿, 새 정보 금지.
- 반론 박스 형식: `> **반론:** ...` 인용 블록, 4·5·6·10장에 하나씩.

## 4. 헤딩 규약

장 `# N장. 제목` / 소절 `## ` / 하위 `### `. 헤딩은 **비대구**(공인 대구 PART 3 제목 제외). 계획서 헤딩을 바꿀 때도 비대구 유지.

## 5. 문체 밴드 (Toby 문체, 과포화도 결함)

| 항목 | 기준 |
|---|---|
| 청유형 `-자/-보자` | 자연스러운 수준. 한 문단 연속·장 전체 도배 금지 |
| 수사적 질문 | 논리 전환 지점에만. 연달아 2개 이상 던지지 않기 |
| 공감어(난감·찜찜·아찔) | 장당 1~2회, 비워도 됨 |
| tic 상한(참고치) | "그렇다면" 장당 4회 이하, "기억해두자/잊지 말자" 장당 2회 이하, "물론 ~다. 하지만" 장당 3회 이하 |
| bold | 대략 80단어당 1개 이하. 책 제목·인용 출처에 bold 남발 금지 |
| 권장 어조 | "반드시 ~해야 한다" → "~하는 편이 낫다" |
| 나열 | 문단을 리스트로 대체하지 않는다. 표는 계획서 배정분(1·3·6·7장 각 1개)만 |
| 외래어 | 직함·고유 용어(DevRel, FDE, MCP)는 원어 유지, 일반어는 한국어로 |

## 6. 사실·신선도 (스타일보다 우선, 위반은 Critical)

- 시점: "최근/요즘" 대신 "2026년 9월 시점", "2025년 11월 기준".
- 수치는 N1~N45·E1~E6만, **조사 주체·표본·문헌 유형 라벨째**. 그 외는 `(사실 확인 필요)`.
- 프리프린트 라벨 대상(Ibrahim & Zaki, Hasan, Gloaguen, Chatlatanagulchai, Guo, Watanabe, Sahni & Chilton, Ali, Peng, METR)은 본문에서 "동료 검토 전 논문(프리프린트)" 명시.
- §7 금지: 26.1%를 개인 해고로, "State of DevRel 2025", Mintlify 66% 단위·벤더 라벨 누락, FDE 800% 라벨 누락, Block 12,000명 "Angie Jones에 따르면" 누락, 공고 건수 추세 단정, Sam Ramji 귀속, "llms.txt가 표준이 됐다", 영향력 증명 61%.
- 전망 문장: [예측] 라벨 + 반대 의견 병기.
- 인용 거처표 준수 — 거처가 아닌 장에서 원문 재인용·인물 재소개는 Should(중복), 전용 인용을 다른 장에서 쓰면 Critical.

## 누적 규율 (파 진행 중 추가)

- **[2026-09-25, 1장 R1] 간접화법 대구도 센다.** "Briggs는 DevRel이 사라지는 것이 아니라 모양을 바꾸는 중이라고 봤다"처럼 출처의 주장을 저자 문장으로 옮기면서 대구 틀을 쓰면 계수한다. 원문 따옴표 인용만 비계수.
- **[2026-09-25, 1장 R1] 인용 직후 풀어쓰기 주의.** 대구형 인용("the role isn't dying. the headcount version is.") 바로 뒤에 "~는 살아남는다. 잘린 것은 ~" 식으로 풀면 계수. 풀어쓸 때는 기준 하나로 서술하자("이 사용자의 기준은 '전후가 있느냐'다").
- **[2026-09-25, 1장 R1] 장 끝 군집 주의.** 대구·수사 질문이 마지막 소절에 몰리는 경향. 클로징 질문 직전 두 문단에는 질문을 두지 않는 편이 낫다.
- **[2026-09-25, 1장 R1] "널리 읽혔다 / 흔히 돈다 / 적지 않은 실무자가" 류는 출처 없는 관찰 일반화로 Critical.** 반응·확산을 말하려면 원장 근거(댓글·조회·인용 출처)를 달거나 리서치 한계 고지("이 책의 조사에서 확인한 사례는 없었다")로 바꾸자.
- **[2026-09-25, 2장 R1] 숨은 대구 형태 추가.** 다음도 계수한다 — "A 대신 B"(저자 문장), "A처럼 보여도 B", "A는 제각각이지만 B는 한목소리"(양보 대비), "X는 여전히 ~. 달라진 것은 Y"(그대로/바뀌었다), 그리고 **`### 이 장의 핵심` 불릿 속 대비 문장**(본문과 같은 대구를 박스에서 되풀이하면 1회 더).
- **[2026-09-25, 2장 R1] 장의 결론 대비를 미리 흘리지 말 것.** 장 끝에서 쓸 대비(예: D 고정/R 이동)가 앞 소절에 양보절·대칭 병렬로 먼저 나오면 대구가 폭증한다. 앞 소절에서는 관찰만 적고 대비는 결론 한 곳에서.
- **[2026-09-25, 2장 R1] 문단 첫머리 "질문 → 답" 반복은 tic.** 한 장에서 소절·문단을 질문으로 여는 것은 절반 이하로.
- **[2026-09-25, 3·4장 R1] "그때/지금" 대비와 "그대로/바뀌었다" 대비가 1~4장 전부에서 초과 원인 1순위.** "예전부터 ~였고, AI는 ~를 늘렸다", "산출물은 바뀌고 만드는 사람은 여전히", "사람에게 ~였듯 에이전트에게도" — 모두 계수한다. 변화는 **이동 동사 하나**("~로 옮겨갔다", "~가 더해졌다")로 쓰자.
- **[2026-09-25, 3·4장 R1] 비계수로 확정한 형태(참고).** 3항 이상 스펙트럼("한쪽 끝 … 다른 쪽 끝 … 그 사이"), 단위·확인 수준 고지("요청 수와 페이지 로드 수", "비율은 조심스럽게, 방향은 가져가자"), 계획서가 요구한 조건부 분리(4-7 두 맥락), 구분 서술 "A와 B는 다르다", 누적 "~도 함께 읽는다".
- **[2026-09-25, 4장 R1] 실무 팁에 넣는 식별자(봇 이름·헤더·경로·플래그)도 레퍼런스(`01_reference.md`·`research/*`·`fact_rules_active.md`)에 있어야 한다.** 없으면 일반 서술로 쓰거나 `(사실 확인 필요)`. (4장 L79 봇 이름은 fact_rules_active F5로 확인됨 — 사용 가능)
- **[2026-09-25, 6장 R1] 표 개수 해석.** "표는 1·3·6·7장에 각 1개"(계획서 §그림)보다 소절 명세가 우선한다 — 6장은 6-1 스냅샷 + 6-5 공고 문구 대조표 **2개 허용**. 다른 장에서 소절 명세에 없는 표를 늘리는 것은 여전히 나열 위험(Should).
