# figure_specs — v1.1.0 표·그림 보강 (append-only)

> 저자 요청(2026-09-25): "기존 책처럼 중간중간에 표, 그림도 최대한 많이". 목표: 전 장 표 ≥1·그림 ≥1, 합계 표 ~15·그림 ~15.
> 그림은 team-lead가 단일 생성기(SVG, 표지 팔레트)로 렌더한다. 저술가는 아래 형식으로 **사양만** append한다. mermaid 5점도 사양으로 다시 적어 같은 스타일로 재렌더한다.
> 번호는 전권 연번(그림 1…N, 표 1…M) — editor가 최종 부여. 저술가는 임시로 `그림 {장}-{k}` / `표 {장}-{k}`로 적는다.
> 규칙: 본문에 이미 있는 내용만 시각화(새 사실·새 수치 금지). 라벨은 짧게(가급적 14자 이내). 수치는 원장·본문 값 그대로 + 라벨(출처 성격) 유지.
> 분량: 표·그림 캡션은 장별 분량 상한에서 제외, 순수 산문만 계측(team-lead 결정, v1.1.0).

## 사양 형식

```
### 그림 {장}-{k} — {짧은 제목}
- 삽입 위치: {장}장 {절} — 이 문단 바로 뒤: "{문단 첫 15자}…"
- 유형: flow | timeline | spectrum | matrix(2x2) | comparison(좌우) | layers | cycle | venn
- 요소: [id] 라벨 · [id] 라벨 · …
- 관계: id → id (라벨) · …   (timeline이면 날짜 | 사건)
- 강조: 코랄로 칠할 요소 id
- 캡션: 그림 {장}-{k}. {캡션 한 문장}
- 근거: 본문 줄 번호 / 원장 항목
```
