# practical 재사용 partial — 환산표·영양표 (v1.11.0)

요리 실용서의 부록에 반복 등장하는 표를 매 책 재작성하지 않도록 한 벌로 둔다. **사용법:** editor가 요리 계열 practical 책의 부록(뒷부속)에 아래 `::: conversion` 블록을 **그대로 복사**해 넣는다 (여행·DIY 등 무관한 책이면 생략). 값은 표준 계량 규약이라 낡지 않는다 — 수정하지 말고 그대로 쓴다. 영양표는 값이 책마다 다르므로 **템플릿만** 제공한다.

---

| 계량 단위 | ml 환산 | 비고 |
|-----------|---------|------|
| 1작은술 (1t) | 5 ml | 티스푼 |
| 1큰술 (1T) | 15 ml | 밥숟가락 수북하지 않게 ≈ 1큰술 |
| 1컵 (1C, 한국 계량컵) | 200 ml | 미국 1 cup은 240 ml — 레시피 출처 확인 |
| 1종이컵 | 약 180 ml | 가득 채우지 않은 기준 |
:::

## 영양표 템플릿 (값은 책별 작성)

레시피 항목에 영양 정보를 싣는 책이면 아래 `::: nutrition` 블록 형식을 쓴다. **값은 반드시 해당 레시피 기준으로 채우고, 출처(성분 DB·계산 방식)를 명시한다** — 근거 없는 수치는 fact-checker의 ⚠️(출처 없음) 대상이다.

```
::: nutrition
영양 정보 (1인분 기준)

| 항목 | 함량 |
|------|------|
| 열량 | 000 kcal |
| 탄수화물 | 00 g |
| 단백질 | 00 g |
| 지방 | 00 g |
| 나트륨 | 000 mg |

*출처: {성분 DB/계산 근거}, 재료·분량에 따라 달라질 수 있다.*
:::
```
