> **(2) 15,379는 "원복 후 값"이 아니다.** editor가 2차로 *"guardian이 잰 15,379는 이미 원복한 상태의 값"* 이라고 적은 것도 오기다. 15,379는 16:33~16:40 구간의 **당시 현행 값**이며 그 시점의 정확한 계측이었다. 원복 결과는 15,548이다. (1)과 (2)는 같은 방향으로 틀렸다 — 둘 다 감축본이 검수를 받았다는 사실을 지운다.
> **(3) 16:28~16:29 변경 주체는 fact-checker가 아니라 editor다.** guardian이 라운드 3 로그에서 mtime만으로 변경 주체를 fact-checker의 front/back matter 패스로 추정했는데 실제로는 editor의 자체 감축이었다. guardian이 추정을 철회하고 자기 로그를 정정했다. **fact-checker는 본문을 건드리지 않았다.**

**실제 발생한 손해는 미검수 유출이 아니라 반복 계측이다.** 이 파에서 원고 자수가 네 번(177,653 → 179,092 → 178,949 → 179,118), 1장 본문이 세 번 움직이는 동안 guardian은 승격 13에 따라 다섯 라운드에 걸쳐 전 지표를 다시 셌다. **개선이 통지 타이밍을 정당화하지 않는다**(승격 17). 상한 위반 발견 시 editor가 먼저 할 일은 감축이 아니라 보고다.

### ⚠️ 뒷부속 분량이 계획서 예산을 초과한 사유 (예외 명시)

`02_plan.md §분량 규약`은 "부록·참고문헌 약 2,000자"로 잡았으나 실제 산출은 26,755자다. **계획서 내부의 불일치이며, 초과 쪽을 채택했다.** 사유는 셋이다.

1. **같은 계획서의 부록 명세가 2,000자로 불가능하다.** 계획서 §앞부속·뒷부속은 부록 A에 **워크시트 9항목**(관문 5개 + 판별 3질문 / SOP 진단표 / 작성 규칙 체크리스트 / 등록 스키마 / 2계층 부여 기준 / 등급표 템플릿 / 환산식과 두 계수 / 선언문 초안 + 커뮤니케이션 4원칙 / 폐기 체크리스트 7항목)을, 부록 B에 **축별 참고문헌 + 출처 성격 라벨 + 접근일 명기**를 요구한다. 표 템플릿 9벌과 서지 목록을 2,000자에 담을 수는 없다.
2. **뒷부속의 대부분이 자수 산정 제외 대상이다.** 같은 §분량 규약이 "표·코드 블록·mermaid·인용 블록은 자수 산정에서 제외한다"고 정했다. 그 규칙을 적용하면 부록 A의 산문은 3,139자이고, 부록 B는 전량이 서지 목록·대조표다.
3. **부록 A는 새 내용을 만들지 않았다.** 본문에서 이미 확정된 표와 판정 규칙을 옮기고 요약한 것이며, 독자가 본문 없이 실무에서 쓸 수 있게 하는 것이 계획서가 부여한 부록 A의 기능이다.
