# Visual Concept — 「디지털 워커의 시대」 그림 규약

표지 팔레트에서 파생한 본문 도판 디자인 시스템. 그림 10점(figures/fig-01~10.svg)은 mermaid 렌더가 아니라 **수제 SVG**다 (v1.2.0 개정에서 교체).

## 팔레트
| 용도 | 색 |
|---|---|
| 종이 배경 | `#f7f3ea` |
| 잉크(본문 글자) | `#26231e` |
| 네이비 박스(핵심 개체) | `#16222e` + 크림 글자 `#f3efe4` / 골드 보조 `#c9b98f` |
| 골드(주 흐름·강조 테두리) | `#c9963f` / 어두운 골드 `#a87f3a` |
| 실패·거부·경고 | `#b4573f` (배경 `#efe0da`) |
| 생존·신뢰 경로 | `#5c7a52` |
| 보조 박스 | `#fffdf8` + 테두리 `#d9cfb8` / 보조 글자 `#6f6a5e` |

## 규칙
- viewBox 폭 1000 고정, 높이 가변. 폰트 Pretendard 계열, 라벨 14–21px.
- 주 흐름 화살표는 골드(굵기 3.5–4), 판정 분기는 다이아몬드(골드 테두리), 실패 경로는 적색 점선/실선, 회귀 루프는 곡선.
- 결핍·공백은 **점선 테두리 + 적색**으로 (예: 그림 4의 여덟째 칸).
- 전권 연번: 그림 1~10, 표 1~11 (장별 리셋 금지). 캡션은 이미지 아래 평문 "그림 N. 제목".
- 다크 모드 웹에서는 CSS가 SVG를 밝은 패널 위에 올린다 — SVG 자체는 항상 종이 배경.
